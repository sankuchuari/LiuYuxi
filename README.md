刘禹锡主题讲评与剧情演绎仓库 (Liu-Yuxi-Project)

欢迎来到本仓库！这里是为大学《中国古代文学》/《大学国文》课程专门打造的刘禹锡主题学习与舞台演绎资源库。

本项目旨在通过学术讲评与情景剧演绎相结合的方式，立体还原“诗豪”刘禹锡波澜壮阔的一生、刚直不阿的傲骨以及豁达坚韧的哲学精神。

📂 仓库目录结构

├── README.md               # 仓库说明文档
├── docs/                   # 学术讲评与人物生平资料
├── script/                 # 舞台剧剧本
│   └── play-script.md      # 8分钟高燃微话剧《前度刘郎》剧本
└── assets/                 # 演出辅助资源


🌟 核心内容导览

1. 学术讲评板块 (/docs)

⚬ 生平全景： 梳理从少年得志、永贞革新到长达二十三年贬谪的传奇历程。
⚬ 文学与哲学： 深度剖析其诗歌的刚健风格（咏史、竹枝词、秋词）、《陋室铭》的独立人格，以及唯物主义哲学著作《天论》。

2. 剧情演绎板块 (/script)

⚬ 剧目名称： 《前度刘郎》
⚬ 演出时长： 约 8分钟（完美契合课堂展示时间）。
⚬ 幕次结构：
  ⚬ 第一幕：风华正茂与永贞革新（意气风发，绝不回头）
  ⚬ 第二幕：玄都观里，傲骨长存（“前度刘郎今又来”，傲视权贵）
  ⚬ 第三幕：晴空一鹤，千帆侧畔（与白居易晚年唱和，生命力拉满）

🎭 演出排练建议

1. 人物基调：
  ⚬ 刘禹锡绝不是一个迟暮落寞的失意老头，而是一个至死眼里都有光的“不老战神”。表演时请着重展现其不屈的傲骨与晚年的通透。
2. 节奏把控：
  ⚬ 8分钟短剧节奏要明快，戏剧冲突层层递进。诗词经典名句（如“前度刘郎”、“晴空一鹤”、“沉舟侧畔”）念白时务必全场停顿、字字砸地，打出气势！
